# Hall of fame

Thank you to everyone who helped make Mosaic safer. Mosaic is pre-audit
software, and this list is a thank-you, not a seal of approval.

## How people are listed

- Only with a clear yes from the reporter. No yes, no listing.
- Each entry has a date, a handle, a finding class and a link to the advisory.
- A link to a profile or site goes in only if the reporter asks for it.
- A reporter can ask us to remove an entry at any time.

## Finding classes

Use one of: vault data or keys, wrong-origin fill, fill without a user click,
sync server, desktop app, native host, CLI, extension, build and release,
other.
